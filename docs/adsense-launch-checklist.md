# 웅이연구소 · 공개/애드센스 신청 체크리스트

1. 실제 PDF·이미지·문서 파일로 11개 도구의 성공·오류·모바일 동작을 점검합니다. 기능 미완료 화면은 공개하지 않습니다.
2. 도메인 ung-lab.com에 Next.js 완성본을 연결하고 HTTPS, 모바일, 전 페이지 200 응답, 내부 링크를 점검합니다.
3. `NEXT_PUBLIC_LAUNCH_READY=true`는 사이트 완성 후 배포 환경에 설정합니다. `/robots.txt` 및 `/sitemap.xml`을 점검하고 Search Console에 등록합니다.
4. 기존 도메인의 색인 URL을 조사하고 실제 일치하는 페이지에만 301을 연결합니다. 일치하지 않는 페이지는 무리하게 홈페이지로 보내지 않습니다.
5. 소개, 문의, 개인정보 처리방침, 이용약관을 실제 운영주체·호스팅·개인정보 처리 및 문의 방식에 맞게 최종 검토합니다. 연락 채널은 실제 수신 가능한 것으로 운영합니다.
6. Google AdSense 심사 신청 시 소유한 계정의 게시자 ID를 `ADSENSE_PUBLISHER_ID=ca-pub-123...` 형태로 설정합니다. 가짜 값은 절대 쓰지 않습니다.
7. 광고 스크립트를 연결하기 전에 배치가 다운로드/업로드/탐색 버튼을 모방하지 않는지 검증합니다. EEA/영국/스위스 등 해당 지역의 동의 관리와 정책 고지를 따로 준비합니다.
8. 승인 여부는 Google이 결정합니다. 특정 게시글 수나 체류 시간만으로 승인을 보장하지 않습니다.

## 자동으로 하지 않는 것
- 도메인/DNS 연결, Search Console 소유권 인증, AdSense 계정 신청 또는 운영자 개인정보 작성
- 동의 없는 광고 코드 삽입 또는 실제 유효하지 않은 ads.txt 발행
- 미완성 사이트의 검색엔진 색인 조기 활성화
