# 웅이연구소 한국어 문구 작성 기준

참고: [im-not-ai / Humanize KR](https://github.com/epoko77-ai/im-not-ai)

- **뜻을 바꾸지 않습니다.** 파일 형식, 기능 제한, 숫자, 개인정보 취급, 외부 통신 등 사실 관계는 그대로 둡니다.
- **화면에서는 짧게 안내합니다.** 버튼은 행동이 드러나게 쓰고, 기능을 여러 번 홍보하는 문장은 줄입니다.
- **번역투를 피합니다.** '이를 통해', '이에 있어서', '~을 수행할 수 있습니다'보다 일상적인 표현을 우선합니다.
- **한 문장에 하나씩 담습니다.** 너무 긴 문장을 나누되 설명이 모호해지지 않도록 합니다.
- **문서별 말투를 지킵니다.** 사용법에서는 친절한 안내체, 정책과 약관에서는 정확한 서술을 사용합니다.
- **과도하게 고치지 않습니다.** 이미 자연스러운 문구, 전문용어, 직접 인용, 법적 책임의 범위는 손대지 않습니다.
- **실제 화면과 맞춥니다.** 지원하지 않는 기능이나 확인되지 않은 보안·승인 주장을 쓰지 않습니다.

이번 패치는 소개·문의·약관·개인정보·헤더·푸터와 주요 도구/가이드 문구를 직접 검토해 수정한 것입니다. 참고 프로젝트의 전문 스킬을 실행했다고 주장하지 않습니다. 도구 관리자(Supabase)에서 별도로 입력한 문구는 DB에서 추가로 확인해야 합니다.
