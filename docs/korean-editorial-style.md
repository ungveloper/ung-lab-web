# 웅이연구소 한국어 콘텐츠 편집 기준

원칙 출처: https://github.com/epoko77-ai/im-not-ai (Humanize KR)

- **사실과 주장 우선:** 도구 지원 형식, 처리 방식, 수치, 파일 보안, 법률·정책 문구를 임의로 변경하지 않는다.
- **사실적인 설명:** 실제 제공하지 않는 기능, AI 처리 능력, 개인정보 보호 수준을 부풀리지 않는다.
- **짧고 자연스럽게:** '이를 통해', '이에 있어서', '시사하는 바가 크다'와 같은 번역투와 장식적인 문구를 줄인다.
- **직접 안내:** '이미지 선택 → 변환 → 미리보기 → 저장'처럼 실제 화면의 동작 순서로 설명한다.
- **말투 유지:** 도구 설명에는 친근한 안내체, 약관·개인정보 문서에는 정확하고 중립적인 문체를 유지한다.
- **의미 검증:** 번역투를 고치더라도 법적 의무·가능성·유보 표현을 확정적인 주장으로 바꾸지 않는다.
- **검수 범위:** UI 고정 문자열, 사용 가이드, 설명·문의·개인정보·약관, 푸시 알림·검증 메시지, Supabase 관리자 관리 문구를 별도로 확인한다.

이 패치는 현재 GitHub 소스에서 확인 가능한 주요 안내 문구에만 **국소적으로 적용**한다. 저장소 스킬 전체를 실행했다고 주장하지 않는다. 더 광범위한 편집 검수는 개발 환경에서 im-not-ai 스킬을 설치해 관련 원문과 대조한 뒤 변경률을 확인한다. 통계나 법적 문구의 자동 일괄 변경은 하지 않는다.
